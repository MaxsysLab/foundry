# Getting Support

- **Questions and how-to:** open an issue and choose the Question template. The
  [README](README.md) covers the commands, the exit codes and what Foundry refuses;
  your answer may already be there.
- **Bugs:** open an issue with the Bug Report template. If a build went wrong, the
  session file and the lines Foundry printed are the most useful things to include.
- **Feature ideas:** open an issue with the Feature Request template. File the issue
  *before* a large pull request (see [CONTRIBUTING.md](CONTRIBUTING.md)). The
  [roadmap](docs/ROADMAP.md) lists what is already planned.
- **Security vulnerabilities:** do **not** open a public issue. Follow
  [SECURITY.md](SECURITY.md).

We aim to give a first response within 3 business days. That is a target, not a
guarantee. Maintainers and contributors are volunteers; please be patient and kind.

Foundry is open-source software offered as it is, without warranty (see
[LICENSE](LICENSE)). There is no paid support through this project.
